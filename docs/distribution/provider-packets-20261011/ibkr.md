# Interactive Brokers — research-provider application

Prepared 11 October 2026 IST. State: **packet ready company fields required**. No new application, agreement or message was sent by this preparation work.

## Proposed recurring use

An analyst reviews source-dated currency context alongside their existing TWS research, saves the evidence and repeats the check. The initial submission is a research-provider qualification, with two actual reports attached; it does not request access to a brokerage account.
