# Financial Evidence 0.1.17 candidate

This source candidate includes the reviewed LiquiLens geography client and
native MCP bridge changes. Publication is pending the signed release workflow
and independent artifact readback. The last verified package remains 0.1.16;
Homebrew remains independently verified at 0.1.13.

## Changes

- The Python product client accepts bounded `lending_geography` reads using a
  district, state or cooperative-bank ID and an optional offset from 0 to 1000.
- The native MCP bridge exposes the tool only when upstream discovery advertises
  it, preserving the upstream schema, source dates, missingness and result.
- The [geography research guide](../agents/GEOGRAPHY_RESEARCH.md) documents
  pagination, source boundaries and reproducible handoffs.
- Release preflight selects the hosted MCP contract from its deployment pin.
  The public router retains independent version 0.1.16 while the package's
  stdio contract advances to 0.1.17.

The existing three-tool stdio routing contract is otherwise unchanged. This
release grants no credit, valuation, trading, training or redistribution rights.
District observations and imagery retain separate source dates; a bank's
documented area of operation is not its measured lending share.

## Publication gates

The native release must verify the trusted SSH signatures on the exact main
commit and tag, consistent package manifests, Python and Node tests, the pinned
live Worker contract, wheel metadata and a fresh installed MCP consumer before
publishing PyPI, OCI, MCP Registry and GitHub artifacts. Publication and consumer
receipts will be added only after independent readback.
