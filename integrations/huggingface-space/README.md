# Financial Evidence Packet Inspector

This static, browser-only Space inspects a Financial Evidence JSON packet
without uploading it. It keeps transport status, evidence evaluation, Evidence
Carrier verification, source-reported state, clocks, and unavailable routes
separate.

The bundled example is synthetic and deliberately includes partial and
warming-up sources. It is not current market evidence.

Live public workflow: https://liquilens.in/evidence-desk/

Source package: https://github.com/beepboop2025/financial-evidence-skills

Financial authority: none. This tool is not investment advice, a credit rating,
or a trading signal.
