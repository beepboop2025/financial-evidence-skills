## What changed

- `financial-evidence connect` selects existing public-research products and
  generates client-neutral `mcpServers` and VS Code `servers` configurations.
- The profile records declared institution/workspace approval, hosted-egress
  approval, source-rights review, subscription inventory and destination choices.
  Generation is offline, records hashes and refuses existing output paths.
- The [institution product/platform matrix](../distribution/institution-product-platforms.md)
  distinguishes current public-research workflows from work still needed for
  private institution systems and third-party subscriptions.
- The bounded Windows Excel operator test and screenshot are recorded separately
  from the earlier web test. Office runtime/manifest code did not change.

The generator does not enforce subsequent request contents, server-side tenant
isolation, vendor entitlements, retention/deletion or regulatory compliance.
It does not connect private systems or external subscriptions. Microsoft and
Google marketplace submission/approval remain separate from this package release.

## Install

```sh
python3 -m pip install financial-evidence==0.1.16
financial-evidence connect --catalog
financial-evidence connect --example > institution.json
```

The example starts with hosted egress unapproved. Follow the
[connection guide](../connect/institution-portability.md) to record actual approval
before generating a package for an approved public-research workspace.
