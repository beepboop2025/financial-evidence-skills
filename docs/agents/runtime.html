Give your agent a research routine.

Run a fixed research question, retain the evidence and pick up where you left off. Financial Evidence 0.1.7 connects LiquiLens bank disclosures, Seiche funding context and Undertow market-liquidity observations to a private, durable workflow.

No data API key is required for the public research inputs. Your state stays on your machine. Package installation starts no service and sends no installation telemetry.

Install the published package

Use Python 3.10 or newer and a local filesystem. Downloaded release artifacts carry checksums and GitHub build attestations; inspect the verification record.

python3 -m venv .venv
.venv/bin/python -m pip install 'https://github.com/beepboop2025/financial-evidence-skills/releases/download/v0.1.7/financial_evidence-0.1.7-py3-none-any.whl'
.venv/bin/financial-evidence-runtime catalog

The core CLI has no package dependencies. The full guide covers optional private MCP, offline acceptance, scheduling and recovery.

Make one recurring question concrete

Download the US-dollar funding workflow. It checks source dates, values, units, rights and whether the returned page is complete. Review its limits, then register it using a private state path:

.venv/bin/financial-evidence-runtime --root /absolute/private/research-state init
.venv/bin/financial-evidence-runtime --root /absolute/private/research-state register runtime-funding-watch.json
.venv/bin/financial-evidence-runtime --root /absolute/private/research-state run funding-watch --key first-review
.venv/bin/financial-evidence-runtime --root /absolute/private/research-state metrics

Retain the returned run ID. Reusing the same key returns the same attempt. A blocked result includes its reasons; missing or old evidence remains explicit. A completed research check grants no trading permission.

Schedule, replay and recover

# Invoke from your scheduler once a minute; at most one due job runs.
.venv/bin/financial-evidence-runtime --root /absolute/private/research-state tick --limit 1

# Replace RUN_ID with the retained identifier.
.venv/bin/financial-evidence-runtime --root /absolute/private/research-state replay RUN_ID
.venv/bin/financial-evidence-runtime --root /absolute/private/research-state backup --output /absolute/new/runtime-backup.sqlite
.venv/bin/financial-evidence-runtime --root /absolute/private/research-state stop

Replay uses the captured bytes without network access. It preserves the original source dates. Backups retain policies, idempotency keys and event cursors. Restore to a new private directory and resume only one copy of the installation.

Connect a private MCP client

Install the package’s workspace extra to use financial-evidence-runtime-mcp --root /absolute/private/research-state as a stdio server. It exposes six tools for catalog, registered jobs, bounded runs, replay, events and metrics. The owner controls job registration and policy; an agent can call only registered jobs.

Evaluate a useful repeat task

Start with one question. Record time to the first useful result, then run it again when a new observation is expected. Use the 14-day scorecard to track useful outcomes and returns. Local runs and package downloads do not establish independent users or revenue.

The runtime stores research evidence. A separate execution host must acquire eligible evidence and enforce its own account and order permissions. Explore that integration.
