# Financial Evidence plugin privacy

This read-only plugin sends the selected dataset, entity filter, limit and offset
to `https://api.seiche.info/openbb/api/v1/query`. Do not enter private customer or
personal data in the entity filter. No account, API key, model permission or
separate telemetry is requested by this plugin. The plugin writes no local data.

The public service stores bounded anonymous daily request/outcome counts. These
do not identify active people. Hosting infrastructure may process network data
to serve and secure requests. Dify and your deployment have their own logging
and data-handling policies. Source usage rights remain with the named publishers.
