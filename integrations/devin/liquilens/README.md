# LiquiLens for Devin

Research India's banks and lenders from their own public filings, with every figure's source document and date.

This folder is the Devin package of the LiquiLens plugin, version
1.0.4. It connects to `https://api.liquilens.in/mcp` without a product API key.
Devin may require its own account or plan.

Install it from a clone of this repository:

```sh
devin plugins install --local ./integrations/devin/liquilens
```

Listing in the Devin marketplace is a separate review; none is claimed here.
The other client packages for this product are in
[`plugins/liquilens`](https://github.com/beepboop2025/financial-evidence-skills/tree/main/plugins/liquilens).
