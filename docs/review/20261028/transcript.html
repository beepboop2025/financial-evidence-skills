Method and package relationship

  • Tests used public, synthetic research requests in one shared API Playground conversation, with approval for individual MCP tool calls. Results are not isolated benchmark trials.
  • The remote MCP endpoint was Financial Evidence MCP.
  • At capture, the tested runtime assets from package 0.1.16 are byte-identical to the runtime assets in the uploaded 0.1.17 draft package. The version update concerns submission metadata; it does not establish a separate native-app test.
  • The captures contain selected visible interaction states. This document does not publish hidden model reasoning, credentials, account identifiers or private customer data.
  • Source repository: financial-evidence-skills. Source freshness, coverage, rights and quote units remain part of each result; successful tool execution does not imply complete or current coverage.

Additional synthesis issue and prompted correction

An additional cross-source synthesis, not included in the video, contained two errors: it labeled the BTC publication time as an observation time and combined costs quoted in USD with costs quoted in USDT.

After an explicit correction prompt, the model separated venue observations at 10:01:17–10:01:20 UTC on 28 October, publication at 10:03 UTC, and evaluation at 10:23:46 UTC. It also separated the USD-quoted venues (Bitfinex, Coinbase, Gemini and Kraken) from the USDT-quoted venues (Binance and OKX), and retained the indicative nature and exclusions of the estimates.

No new MCP call was made during that correction. The correction depended on a follow-up prompt; this is an observed limitation, not a clean first-pass result or proof that future answers will avoid the same errors. Referenced source endpoint: Undertow crypto desk JSON.
