Excel add-in privacy

Updated 18 October 2026. Provided by LIQUILENS PRIVATE LIMITED.

The add-in sends only the currency codes and institution slugs you enter, with ordinary request metadata, to the public research service. It does not send workbook contents, cell values, sheet names, your Microsoft identity or credentials. No account or API key is required by the research service.

The ReadWriteDocument permission lets the add-in read worksheet names to avoid collisions and insert new, clearly named review sheets into the workbook where you opened it. It does not read existing cells, edit existing sheets, monitor your work or run a background refresh. Requests occur only when you select Refresh research; insertion occurs only when you select Insert new review sheets.

No cookies, installation identifiers, advertising analytics or local storage are added by this code. Microsoft Office.js and hosting/network providers process ordinary service metadata under their own policies. Service-side operational counters and retention are described in the Financial Evidence privacy policy.

Review data stays in memory while the task pane is open and in the new workbook sheets or evidence file you choose to save. Clear or remove those files through your normal workbook controls. Closing the add-in ends its in-memory session. Removing it prevents further use, but does not delete sheets you inserted.
