Finance-agent developers: get a cited funding result

Add one named dataset to your existing research step. This request returns a bounded USD funding sample, its original observation date, source and coverage:

curl --fail --max-time 30 \
  'https://api.seiche.info/openbb/api/v1/agent-query?dataset=money_markets&entity=USD&limit=5'

For MCP, connect https://api.seiche.info/openbb/mcp, discover its schemas and call financial_evidence_agent_query with {"dataset":"money_markets","entity":"USD","limit":5}. Inspect next_offset for more rows. Save the response and its revision; repeat the same task on another day, checking source dates even when the result is unchanged.

Treasury and bank-risk teams: start with your watchlist

The new LiquiLens institution monitor organizes supported deterioration alerts, source-dated disclosures and evidence gaps. Choose exact institution identifiers from the live register:

curl --fail --max-time 30 \
  'https://api.liquilens.in/api/experimental/v1/banking/monitoring/watchlist?slugs=au-sfb,bajaj-finance'

Or call institution_evidence_monitor at https://api.liquilens.in/mcp with {"slugs":["au-sfb","bajaj-finance"]}. These are illustrative institutions. Retain the review queue for your own counterparties and compare the next working day's disclosures and unresolved gaps. Missing evidence does not establish safety; a disappearing warning is not proof of recovery.

Keep the workflow useful

Retain the first output, record what it helped you review, and return for a second task. Use the 14-day evaluation scorecard to track usefulness and blockers with the participant's consent. The developer, risk-team and individual-researcher cohorts stay separate. These examples do not enroll users or configure background jobs.

Once a first task works, set up recurring research with retained receipts and recovery. NoiseFloor 0.3.1 adds descriptive analysis of your own entitled series and headlines. The browser paper walkthrough separately rehearses order controls with synthetic data.

Repeat checks without repeating every row

Save the response's revision and pass it as previous_revision on the same query. Identical published evidence omits duplicate rows while returning source metadata. Partial and failed retrievals always return diagnostics. Unchanged does not mean fresh. Check source dates, availability, rights and limitations on every run.

Know the coverage

Each value retains its original date, unit, source URL, source path and content hash. Withheld or unavailable values remain missing. Bank diagnostics are research measures; market percentiles are not executable quotes. These tools supply evidence for human-reviewed research and have no trade-execution authority.
