The published 0.1.10 package includes persistent MCP sessions and the source-status clients. The hosted services have separate release identities.

Python 0.1.10 bounds the wait for a complete source-status event even when partial bytes or comments arrive. Python and JavaScript require an initial reset before a keepalive; npm AI SDK 0.1.1 includes the synchronized client. These tools retain no trade-execution authority.

The doctor makes bounded anonymous checks of four public research connections and the source monitor. It labels its requests synthetic. Its result separates connection success from freshness, restrictions and unknown coverage; a passing connection check does not qualify an input for trading.

Python: reuse a product MCP session

One client context owns the session for a bounded job. This diagnostic example marks its calls as test traffic.

import asyncio
from financial_evidence.trading import ProductClient

async def main():
    async with ProductClient(mode="test", timeout=15) as client:
        first = await client.call("seiche", "data_health")
        again = await client.call("seiche", "data_health")
        print(first["timing"], again["timing"])

asyncio.run(main())

Repeated calls reuse initialization. Failed calls are not automatically replayed. Timing describes the client request, while each observation keeps its own source clock.

JavaScript: follow source status

Download context-client.mjs beside your script. Use Node 22+ or a modern fetch runtime.

import {
  contextSnapshot, contextEvents
} from './context-client.mjs';

console.log(await contextSnapshot());
for await (const event of contextEvents({timeoutMs: 30000})) {
  if (event.event === 'reset') {
    console.log(event.data);
    break;
  }
}

The stream begins with the latest full state. Reconnects do not replay every update. Python's ContextClient provides the same snapshot and event contract.

Check the source, even when the connection works.

  • Monitor age and source age differ. Recheck valid_until while holding a snapshot. A current monitor can report stale, restricted or unknown sources.
  • A heartbeat proves transport liveness. It does not refresh an observation or turn a daily reference rate into a tick quote.
  • Access and permitted use differ. Retain source URLs, units, observation dates, restrictions and missing values. Public access does not grant redistribution or execution rights.

Snapshots are prepared from the scheduled source monitor. Reading the snapshot or stream does not trigger an upstream market-data fetch.
