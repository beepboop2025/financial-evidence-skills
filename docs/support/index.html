Financial Evidence

Support

Financial Evidence is public, read-only research infrastructure with no account or paid support tier.

Before reporting a problem

  • Run financial-evidence doctor --format table for terminal installations.
  • For remote clients, confirm the MCP URL is https://liquilens.in/mcp/financial-evidence.
  • Keep partial and unavailable states intact; they may reflect a public source outage rather than a client error.

Get help

For reproducible bugs, open a public GitHub issue with the client name, topic, retrieval time, and redacted error. For security reports, use the security policy. For other support questions, email mrinal@liquilens.in.

Do not include credentials, private financial records, personal information, or confidential source material in a report.
