## Remaining gate

The current free User App Share form requires a NinjaTrader-exported source ZIP, version, description/setup instructions, screenshots and disclosure acceptance. Loose C# or a generic ZIP is not an accepted native export. Native runtime, support and present vendor-program eligibility remain required.

The fresh form explicitly rejects compiled/protected components and external DLL references for User App Share. Screenshot minimum is 250×250, individual uploads up to 8 MB and total attachments under 24 MB. No native add-on or vendor application was submitted.
