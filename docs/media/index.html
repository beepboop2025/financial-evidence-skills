Work with the evidence

Open a briefing without registration. For a newsroom evaluation, send the question, deadline, institution or market, and required format to Mrinal Singh at mrinal@liquilens.in. We can discuss a scoped evaluation; no turnaround or coverage commitment is made until agreed.

For recurring research, connect the funding API or use the spreadsheet, notebook and agent tools. Data teams can inspect the edition catalog, funding contract and platform evaluation packet.

Seiche covers system funding evidence; LiquiLens covers specified institution disclosures. These briefings do not establish a combined stress score, universal bank coverage or an institution’s current ability to meet withdrawals.
