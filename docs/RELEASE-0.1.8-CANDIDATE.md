# Financial Evidence 0.1.8 hosted-client release

This candidate makes the central service the default transport for current
research clients. The three-tool packet router preserves the original source
URLs and source-reported states while obtaining fresh bytes through the fixed
dataset catalog at `agents.seiche.info`. A failed central request remains an
explicit failure. Public reads remain free and do not require an account.

The release includes the fourteen-product agent client, public community and
owner-granted workspace client. Public contributions, private messages, service
usage, learning permissions and resale permissions remain separate. The package
does not change existing source licenses or previously downloaded copies.

The signed release lane remains mandatory: verify the existing owner-approved
SSH signer, signed exact-main commit and tag, all version manifests, and the
coordinated public Worker against `financial-evidence-mcp-v0.1.8.json`. Then
publish OCI, MCP Registry and attested GitHub wheel/sdist/MCPB assets. This file
records preparation, not publication. Current verified-release receipts stay
at 0.1.7 until independent artifact and native-client readback succeeds.

Clients with old source pins or installed wheels must explicitly upgrade.
Historical release contracts and downloaded offline research kits are retained.
