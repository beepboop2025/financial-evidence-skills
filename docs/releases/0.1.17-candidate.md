## What changed

The Python product client supports bounded LiquiLens `lending_geography` reads
using district, state or cooperative-bank IDs and an optional integer offset
from 0 to 1000. The native MCP bridge exposes the tool only when upstream
discovery advertises it, preserving its schema and result. The
[geography research guide](../agents/GEOGRAPHY_RESEARCH.md) explains pagination,
source dates, coverage, missingness and reproducible handoffs.

Release preflight now selects the hosted MCP contract from its verified Worker
pin. The public router remains independently versioned at 0.1.16; this package's
stdio contract advances to 0.1.17 with the same three tools and eight topics.

District observations and imagery retain separate source dates. Missing values
remain unavailable, and a bank's documented area of operation is not a measured
lending share. This release grants no credit, valuation, trading, training or
redistribution rights. Satellite imagery does not establish title or value.

## Install

```sh
python3 -m pip install 'financial-evidence[workspace]==0.1.17'
financial-evidence connect --catalog
financial-evidence start
# Alternatively, install the verified Homebrew formula:
brew install beepboop2025/tap/financial-evidence
```

The optional workspace dependencies support the product client and native MCP
bridge. Follow the geography guide before making a permitted public research
request. Fresh installation and publisher-operated tests do not establish
external adoption, paid use, source-data accuracy or marketplace approval.
