Keep the next step clear.

The connection works, but there is no result

Check the returned source diagnostics and coverage. The selected institution, currency or size may be unavailable. Keep missing values explicit and try a supported selection in the Research Desk.

My client does not accept a remote MCP URL

Use the client-specific setup guide. Some clients need a JSON configuration or a local adapter. The version-pinned terminal router is another option; its three topic tools have a different scope from this hosted workflow server.

I need a chart for a report or an article

The Media Desk provides dated charts, downloadable data and source references. Read the attribution and reuse notes before publication.

Our team needs different coverage

Inspect the team evaluation guide and define the task, required sources and reporting lag. Platform admission, source permissions and commercial terms are assessed separately.
