For financial platform and data teams

Evaluate a defined evidence feed.

Start with one analyst task and a small set of fields. These dated packets let a platform team inspect the evidence before agreeing an integration.

EvaluationAvailable materialScope to agree
Dollar-funding research cardDated nine-input review, source-reconciled calculations and chart; REST delivery contract.Permitted fields and reuse; rate/operation/balance dates; source refresh; stale-source handling; attribution and delivery expectations.
Covered-bank disclosure cardDated single-bank disclosure comparison, reporting periods, primary filing references and explicit omissions.Actual institution and period intersection; data-field completeness; factual extract vs document delivery; verification and source-specific rights.
Reference FX sampleFour ECB EUR reference series, CSV/JSON sample, schema and source reconciliation.Non-exclusive public-source value proposition, current-amended history, source notices and eventual commercial fit.

Proposed evaluation

  1. Select one recurring user question and confirm the relevant fields and coverage.
  2. Review source-specific reuse, exact sample values, missingness and refresh behavior.
  3. Agree a time-limited evaluation with named evaluators and an integration surface. A proposed starting scope is two evaluators and ten tasks over fourteen days.
  4. Measure completed tasks, source-checking accuracy, time to an answer and voluntary repeat use separately. Expand only after the intended users find the evidence useful.

Those numbers describe a proposed evaluation, not existing users, an SLA or promised adoption. Hosting, licensing, support and commercial terms remain to be agreed. Platform admission and native integration acceptance are separate from a successful API response.
