Deliberate boundary

Inspection is not execution.

  • No brokerage, order, portfolio, custody, or write API is present.
  • No account, API key, or personal data is requested.
  • No received identifier is inserted into an outbound URL.
  • Missing, restricted, or failed evidence is never converted to zero or calm.
