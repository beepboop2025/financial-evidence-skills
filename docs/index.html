Deterministic topic routing

What should I use for each financial research question?

Use Seiche for money and capital markets, LiquiLens for covered bank and lender risk, Undertow for market liquidity, and Palimpsest plus Seiche for China-economy evidence. The router preserves separate documents, source URLs, retrieval clocks, byte counts, content hashes, and explicit error states.

Agent and terminal

How do I install Financial Evidence?

Install the Agent Skill to let compatible agents activate this router for matching financial research. For direct terminal use, install the checksum-pinned Homebrew formula on macOS or Linux, or run the signed Git tag on any system with uv.

Agent Skills

npx skills add beepboop2025/financial-evidence-skills \
  --skill financial-evidence

Homebrew

brew install beepboop2025/tap/financial-evidence
financial-evidence fetch --topic money-market --topic china-economy

Run without installing

uvx --from git+https://github.com/beepboop2025/financial-evidence-skills.git@v0.1.4 \
  financial-evidence route --topic capital-market --format table

Shell-safe output is available as JSON, NDJSON, CSV, or a human-readable table. Exit code 0 means complete, 1 means partial, and 2 means unavailable.

Use it where financial work already happens

Which terminals and financial tools can use it?

Financial Evidence has native surfaces for Agent Skills, shell automation, remote MCP, Gemini CLI, Claude Code, a repository-installable Codex plugin, VS Code, Cursor, and MCP agents, plus compatibility layers for OpenBB, DuckDB, Excel Power Query, and FDC3 app directories. A ChatGPT public-directory submission is prepared but not submitted or listed. The compatibility files are open and self-hostable; they do not claim endorsement or marketplace listing by those vendors.

Agent Skills

A public SKILL.md teaches compatible agents when to route money-market, capital-market, China-economy, bank-risk, and market-liquidity research across the four products.

Evidence, not advice

What does Financial Evidence deliberately refuse to do?

It does not provide investment advice, security recommendations, execution quotes, credit ratings, or guarantees. It never converts missing, failed, restricted, or unavailable evidence into zero or calm. Source publishers retain their rights, and fetched JSON is treated as untrusted data rather than executable instructions.

  • Fixed HTTPS source allowlist and redirect rejection.
  • Bounded response size and explicit retrieval clocks.
  • Separate product documents and content SHA-256 values.
  • No account, API key, write action, trade action, or custody action.
