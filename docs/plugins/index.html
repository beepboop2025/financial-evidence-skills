Directory publication

This is our publisher-maintained catalog. OpenAI requires verified publisher identity; Claude Directory requires an eligible paid publisher plan. Neither official directory approval is claimed. Existing Cursor, Cline, Kilo and other applications retain their individual review status in the distribution tracker. Gemini's public gallery indexes qualifying repositories separately.

The Plugin ZIP is a prepared OpenAI upload, not an approved store listing. It contains public manifests, one MCP connection, a research skill and logos. The public service needs no product API key; assistant accounts may have their own fees.
