Download the Node-RED flow

Start in three steps.

  1. Import. Download the JSON above. In Node-RED, choose Menu → Import → select a file to import, then import it into a new flow.
  2. Run one task. Select Deploy, then click the small Inject button next to USD money-market preview, AU SFB filing preview or BTC indicative liquidity preview. Deploying alone does not fetch data.
  3. Inspect. Open the Debug sidebar. Expand Evidence preview, read warnings, then expand table.results and table.sources. Errors appear separately under Research request needs attention.

Each click makes one read-only public query. Nothing runs on a timer, sends a message or places a trade.

Choose the research question.

USD money markets

Inspect published USD benchmark observations with their native units and source dates. Rate levels alone do not establish funding stress.

Default: money_markets, entity USD.

Covered-bank filings

Inspect AU Small Finance Bank's covered filing evidence. Keep reporting periods, citations and interpretation limits. Coverage is limited and these are not credit ratings.

Default: bank_risk, entity au-sfb.

Indicative BTC liquidity

Inspect published BTC-related research measures with their coverage and validation limits. These are not executable quotes or a sized order estimate.

Default: market_liquidity, entity BTC.

Double-click a task's Inject node to change its JSON payload. entity matches a substring; choose a supported dataset and a limit from 1 to 200. The default limit is 25. Use synthetic: true for operator or CI tests; leave it false for your own research.

Keep the result's limits visible.

The full response remains in table: source URLs, content hashes, observation and retrieval dates, units, rights, missing values, diagnostics and source-reported states are retained.

pagination_complete says whether more matching rows exist. transport_complete describes retrieval. source_partial_reported flags a source reporting partial or unavailable evidence. Successful retrieval does not prove freshness or complete coverage.

This flow reads one page per click and does not automatically follow pagination. Narrow the entity filter if more rows exist, or use the bounded Python capture for a full export.

Missing and restricted values remain null. Unknown rights remain unknown; public access and MIT flow code do not grant source-data redistribution permission. Review each row's dates and interpretation limits before using it in your work.
