# Databricks — Financial Evidence Research MCP

Prepared 11 October 2026 IST. State: **packet ready provider qualification**. No new application, agreement or message was sent by this preparation work.

## Proposed recurring use

Enterprise agents retrieve a bounded page of financial research, retain its source dates and missingness, and repeat the same review on the next working day. The proposed listing distributes connectivity to the existing hosted research service. A downloadable data share, if later wanted, is separately limited to the reviewed ECB sample contract.
