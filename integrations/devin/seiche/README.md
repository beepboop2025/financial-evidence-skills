# Seiche for Devin

Research public money markets, regional funding context, GIFT City and gold carry using verified direct-source tools.

This folder is the Devin package of the Seiche plugin, version
1.0.4. It connects to `https://api.seiche.info/mcp` without a product API key.
Devin may require its own account or plan.

Install it from a clone of this repository:

```sh
devin plugins install --local ./integrations/devin/seiche
```

Listing in the Devin marketplace is a separate review; none is claimed here.
The other client packages for this product are in
[`plugins/seiche`](https://github.com/beepboop2025/financial-evidence-skills/tree/main/plugins/seiche).
