Privacy

Last updated 24 August 2026.

What the service receives

Financial Evidence requires no account, API key, or payment information. A request contains only the selected research topic or topics and ordinary protocol metadata needed to return a response. Please do not put personal or confidential information into a topic request.

Infrastructure data

The public documentation and remote MCP endpoint are delivered using GitHub Pages, Cloudflare, and the four public product surfaces. Those providers may process standard security and delivery logs such as IP address, user agent, timestamp, requested path, and operational error information under their own policies. The evidence router may make allowlisted upstream requests needed to retrieve the selected public evidence.

Use and sharing

Liquidity Lab uses operational data only to secure, diagnose, rate-limit, and operate the service. It does not sell personal information, build advertising profiles, or intentionally collect sensitive personal data through this service. Data may be disclosed when required by law or needed to protect the service and its users.

Retention and contact

Operational logs are retained according to the configured infrastructure providers and may differ by surface. For privacy questions or a request concerning data controlled by Liquidity Lab, email mrinal@liquilens.in.
