Prepare a live-broker integration
The separate customer-owned Alpaca connector supports bounded limit orders, long-only exposure, cash and daily-loss checks, STOP, cancellation requests and reconciliation. It starts disabled. A live order requires the customer’s account mandate, qualified live evidence, a verified broker-preview reference and an authenticated receipt for that exact order.
Available as an integration candidate; no managed live-trading service or real broker fill is claimed. Public research data and this simulator do not qualify an account for live execution. Broker eligibility and data entitlements depend on the customer.
